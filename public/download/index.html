Verify download

校验下载的文件

下载完成后，在文件所在目录运行对应命令。命令里已经带上本页列出的 SHA-256，输出 True 或 OK 即说明文件完整、未被改动。

Windows · PowerShell

Get-FileHash .\acecode-<版本>-windows-x64.zip -Algorithm SHA256

输出的哈希值应与本页列出的 SHA-256 一致（不区分大小写）。

macOS · 终端

shasum -a 256 ACECode-<版本>-macos-arm64.pkg

输出的哈希值应与本页列出的 SHA-256 一致。

Linux · Shell

sha256sum acecode-<版本>-linux-x64.tar.gz

输出的哈希值应与本页列出的 SHA-256 一致。

每个版本的完整校验清单也可以在 SHA256SUMS-<版本>.txt 中查看。
